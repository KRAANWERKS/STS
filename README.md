# SUPERFAST — PT Solusi Transshipment Supercepat

Cinematic company website for SUPERFAST offshore dry-bulk transshipment services.

## Local preview

Serve the repository with any static web server, for example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

A GitHub Pages workflow is included under `.github/workflows/pages.yml`.
Set **Settings → Pages → Source** to **GitHub Actions** if it is not already enabled.

> The repository is private. GitHub Pages availability for private repositories depends on the organization plan and policy.

## Content notes

Fleet capacity figures are target/planned operating capacities and are intentionally labelled as such where applicable. Actual performance depends on cargo, vessel, barge continuity, sea state, operating restrictions, crew execution and stoppages.
